# SONARA DAW + ORPHEUS AI — Product Roadmap

## Phase 1: Core Engine (Foundation)
- [ ] C++ / JUCE audio engine with multi-buffer architecture
- [ ] ASIO, CoreAudio, WASAPI driver support
- [ ] VST3, AU, and CLAP plugin hosting with sandboxing
- [ ] Basic arrangement view (linear timeline)
- [ ] GPU-accelerated piano roll
- [ ] Basic mixer with unlimited tracks and busses
- [ ] MIDI and MPE device support
- [ ] Mackie Control and HUI protocol support
- [ ] Autosave and session recovery

## Phase 2: DAW Feature Parity
- [ ] Session View (clip-launch environment)
- [ ] Take lanes and comping system
- [ ] Warp engine (time-stretching and pitch-shifting)
- [ ] ARA2 plugin integration
- [ ] Notation / Score editor
- [ ] Modular modulation system
- [ ] Expression maps and articulation management
- [ ] Scratch Pads (alternate arrangements)
- [ ] Video track and SMPTE timecode sync

## Phase 3: ORPHEUS AI Integration (Core)
- [ ] Natural Language Interface (NLI) — text command parsing
- [ ] ORPHEUS-Vocal: Pitch correction and vocal synthesis
- [ ] ORPHEUS-Mix: AI EQ and dynamic balancing
- [ ] ORPHEUS-Master: AI mastering with LUFS targeting
- [ ] ORPHEUS-Repair: Noise reduction and spectral repair
- [ ] ORPHEUS-Harmony: Chord generation and voice leading
- [ ] ORPHEUS-Performer: MIDI humanization and groove

## Phase 4: ORPHEUS AI Integration (Advanced)
- [ ] ORPHEUS-Stem: High-fidelity source separation
- [ ] ORPHEUS-Arrange: Song structure generation
- [ ] ORPHEUS-Replace: Audio-to-MIDI and instrument replacement
- [ ] ORPHEUS Memory System: User workflow learning
- [ ] Voice command input for ORPHEUS
- [ ] ORPHEUS Educational Mode: Theory explanations and mix breakdowns

## Phase 5: Spatial Audio & Post-Production
- [ ] Dolby Atmos renderer and 3D panner
- [ ] Binaural monitoring
- [ ] Multi-channel busing (7.1.4, 9.1.6)
- [ ] ADR system with speech-to-text marker generation
- [ ] Broadcast loudness compliance (EBU R128, ATSC A/85)

## Phase 6: Collaboration & Cloud
- [ ] Real-time multi-user session collaboration
- [ ] Cloud project sync and version history
- [ ] Stem sharing and remote feedback system
- [ ] SAMPLESOCIETY cloud marketplace integration

## Phase 7: Stock Plugin Suite
- [ ] SONARA Synth One (Wavetable)
- [ ] SONARA Analog (Virtual Analog)
- [ ] SONARA FM (6-Operator FM)
- [ ] SONARA Granular
- [ ] SONARA Orchestra
