# SONARA Arrangement View Specification

## 1. Overview
The SONARA Arrangement View is the primary linear timeline for composing, arranging, and editing music. It combines the best features of Ableton's Arrangement View, Studio One's Song Page, and Pro Tools' Edit Window.

## 2. Core Features

| Feature | Description |
| :--- | :--- |
| **Linear Timeline** | Standard horizontal timeline with bar/beat grid. |
| **Track Types** | Audio, MIDI, Instrument, FX Return, Bus, Video, and Marker tracks. |
| **Clip-Based Editing** | All audio and MIDI content is contained in clips for non-destructive editing. |
| **Clip Gain** | Per-clip gain adjustment without affecting the track fader. |
| **Warp Engine** | Advanced time-stretching and pitch-shifting with multiple algorithms. |
| **Take Lanes** | Multiple takes recorded in stacked lanes for easy comping. |
| **Crossfades** | Automatic and manual crossfades between adjacent audio clips. |
| **Batch Fade Engine** | Apply fade-in/out to multiple clips simultaneously. |
| **Scratch Pads** | Multiple alternate arrangements of the same project for comparison. |
| **Markers & Regions** | Named markers and colored regions for navigation and structure. |

## 3. Dual-View Workflow (Ableton-inspired)

SONARA features two complementary views:

* **Session View:** A clip-launch environment for live performance and non-linear composition. Clips are organized in a grid and triggered manually or via Follow Actions.
* **Arrangement View:** The standard linear timeline for finalizing arrangements.

Content flows seamlessly between both views.

## 4. ORPHEUS AI Enhancements

| ORPHEUS Feature | Description |
| :--- | :--- |
| **AI Structural Arrangement** | Generates a full song structure (Intro, Verse, Chorus, Bridge, Outro) from a loop or motif. |
| **Transition Building** | Automatically generates fills, risers, and drops between sections. |
| **Phrase-Aware Time Stretching** | Stretches audio while preserving the natural phrasing of the performance. |
| **AI Arrangement Comparison** | Scores multiple Scratch Pad arrangements for energy, flow, and structure. |
| **Follow Action Intelligence** | Learns from user behavior to suggest adaptive clip sequencing rules. |
